把划线和想法拆成资料卡，再按细标签召回，服务于写作、评论和选题。

等待载入本地数据。

资料不是靠记，是靠扣住

从微信读书同步划线与想法，形成可检索、可写作调用的个人资料夹。

会优先使用当前选中的细分类。
/user/notebooks 获取所有有笔记的书。分页只用 count + lastSort，用于同步书目、计数和最近笔记时间。
/book/bookmarklist 获取单本书划线内容和章节信息。划线会变成 highlight_card，并附上微信读书跳转链接。
/review/list/mine 获取单本书个人想法与点评。能按 range 关联到划线的，会合并成 linked_card。
/api/material-pack 本地加工接口：按主题召回资料卡，输出可引用原文、你的想法、焦点标签和写作提纲。
/api/classify 向量分类接口：调用 BGE 模型对所有笔记做 embedding，按余弦相似度匹配到 75 个预建分类。需要先启动 npm run embed。
/api/classified 获取已分类数据：返回所有笔记的向量分类结果和统计信息。
