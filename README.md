# 微信读书工作室小程序版

这是从原 Vue 网页版迁移出来的微信小程序项目。当前版本以小程序原生页面承载主要体验，UI 按提供的设计图重做为暖米白纸感、黑色内容卡、橙金强调色和底部 Tab 导航。

## 页面

- 首页：阅读统计、最近素材、知识重组入口
- 书架：在读/已读/想读分组、阅读进度卡片
- 书籍详情：进度、阅读轨迹、AI 理解摘要
- 笔记：搜索、标签筛选、笔记卡片流
- AI：阅读宇宙问答入口和推荐问题
- 分类、设置、同步、搜索、个人中心等辅助页

## 微信开发者工具运行

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本仓库根目录：`C:\projectVue\projectVue\we`。
4. AppID 可先使用测试号，或把 `project.config.json` 里的 `appid` 改成你自己的小程序 AppID。
5. 编译后从 `pages/home/home` 进入。

## 部署

本版本不再使用 Railway、Vercel 或 Express 网页服务部署。最终发布流程走微信小程序：

1. 在微信开发者工具中完成预览和真机调试。
2. 配置合法域名。如果后续接入云函数，优先使用微信云开发，不要把 Cookie、OpenAI Key 等密钥放进小程序前端包。
3. 点击“上传”，在微信公众平台提交审核。

## 数据接入建议

当前小程序页面使用 `utils/data.js` 中的演示数据，便于先完成界面和交互迁移。真实数据接入建议拆成两层：

- 小程序前端只负责展示、搜索、跳转和触发同步。
- 微信云函数负责读取微信读书同步数据、调用 AI，并把敏感配置保存在云环境变量里。

仓库中原有 `fetch-data.js`、`classify.js` 和 `lib/` 仍可作为迁移云函数时的参考实现。
